# Quick start

Send your first event and see it in your app's log, in a few minutes. You don't need an account
with any analytics service yet: you start with Herald's log module, which prints each event instead
of sending it. At the end you add Firebase.

Pick your platform:

<div class="grid cards" markdown>

-   :material-android:{ .lg .middle } **[Android](android.md)**

    Kotlin, on Maven Central.

-   :simple-apple:{ .lg .middle } **[iOS](ios.md)**

    Swift, through Swift Package Manager.

-   :simple-flutter:{ .lg .middle } **[Flutter](flutter.md)**

    Dart, on pub.dev.

-   :simple-react:{ .lg .middle } **[React Native](react-native.md)**

    TypeScript, on npm. Works with Expo.

-   :simple-kotlin:{ .lg .middle } **[Kotlin Multiplatform](kmp.md)**

    Events in shared Kotlin, over the Android and iOS SDKs.

</div>
